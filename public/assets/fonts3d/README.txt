Keychain fonts, converted and subset by scripts/build-kc-fonts.py from Google Fonts:

  kc-script.json   Pacifico          SIL Open Font License 1.1  (OFL-Pacifico.txt)
  kc-brush.json    Damion            SIL Open Font License 1.1  (OFL-Damion.txt)
  kc-hand.json     Satisfy           Apache License 2.0         (LICENSE-Satisfy-Apache-2.0.txt)
  kc-rounded.json  Fredoka SemiBold  SIL Open Font License 1.1  (OFL-Fredoka.txt)

None of these fonts declares a Reserved Font Name, so the converted subsets may
keep their names. Only the characters the keychain designer accepts are kept,
and overlapping contours are merged per glyph.
